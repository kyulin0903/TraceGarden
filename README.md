# TraceGarden (남겨진 뜰)

요정이 주인공인 탑다운 2D 농장 게임입니다. 현재 개발 중입니다.

- 엔진: Unity 6 (6000.3.14f1), URP 2D
- 입력: New Input System
- 목표 플레이타임: 2~3시간

## 조작

| 키 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| F | 밭 근처에서 농사 모드 진입 / 종료 |

## 구현 내용

- **캐릭터 이동과 방향 전환** ([Character.cs](Assets/Scripts/Character.cs))
  이동 방향에 따라 좌우 스프라이트를 교체합니다. 배경 스프라이트의 경계를 기준으로 이동 범위를 제한합니다.
- **카메라 추적** ([CameraFollow.cs](Assets/Scripts/CameraFollow.cs))
  캐릭터를 따라가되 카메라 화면이 배경 밖으로 나가지 않도록 경계를 계산해 위치를 고정합니다.
- **밭 상호작용 감지** ([Interaction.cs](Assets/Scripts/Interaction.cs))
  트리거 콜라이더로 밭에 가까이 갔는지 감지하고, 가까이 있을 때만 F키 안내를 띄웁니다.
- **농사 모드** ([FarmMode.cs](Assets/Scripts/FarmMode.cs))
  F키를 누르면 카메라가 밭 중앙으로 부드럽게 이동하며 확대되고, 다시 누르면 원래 위치와 크기로 돌아옵니다.

## 개발 계획

하루 단위로 반복되는 농장 생활을 중심으로, 밭과 요정을 키워 가며 스토리를 진행하는 구조로 만들 예정입니다.

- 낮에는 농사, 탐색, 상점 이용 / 밤에는 미니게임 후 다음 날로 진행
- 작물을 키워 판매하고, 번 돈으로 씨앗, 도구, 요정을 강화
- 밭 확장과 새 작물 해금
- 다른 장소로의 이동과 스토리 진행
